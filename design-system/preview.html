Form controls · component design

All controls are quiet: no fills or boxes, one dark ink, one focus color. States are shown side by side (forced) and the last cell of each row is live.

Text field

Underline only. Label is a small UPPERCASE caption above. Hover darkens the line, focus makes it a 2px dark line (`border.focus`), error makes it 2px red plus a message with ⚠ (never color alone). Height follows density (32/40/44).

Slider

For ranges where approximate is fine or the range is large (EVs 0–252, IVs 0–31, level 1–100). Always paired with a mono number field showing the exact value (typing is the precise path; the slider is the fast path). Thin 4px track in the data colors, 20×12px filled dark oblong thumb, 44px touch height, no tick marks. Arrow keys ±1, PageUp/Down ±10, Home/End.

Selection, tabs, EV/IV strip, key-value rows

Compact density (32px rows), as on the detail and build pages. All live.

Searchable list (combobox) and multi-select

Same underline trigger and hairline menu as the dropdown. Typing filters the list and bolds the match; ↑↓ move, Enter selects, Esc closes. Use for long lists (moves, items, abilities: 15+ options). Multi-select keeps the menu open, shows ✓ per chosen option, and the trigger summarizes ("Fire, Flying" or "3 selected").

Tabs

Text only, muted when idle; selected = accent color (no bold, no underline). Optional muted count. Hover darkens text. Keyboard: ←/→ move and select, Home/End. When tabs overflow, the row scrolls horizontally (no wrapping, no “more” menu). Max ~6 tabs; beyond that use a dropdown.

EV / IV strip

One row per stat: EV slider + exact field, IV field, resulting stat. Header shows EV total remaining (muted; danger color + “over by N” text when above 510). Fields clamp to range on blur (EV 0–252, step 4; IV 0–31). The slider is optional at touch widths; the fields always remain.

Key-value row

Muted label left, mono value right, hairline between rows, 1–3 columns by width. Value types: plain, with unit (muted), empty (“—”), editable (underline field, same as text field but right-aligned), link (semibold, bold on hover), text values (sans, e.g. ability names). Rows never wrap the label; long values truncate with a tooltip.
