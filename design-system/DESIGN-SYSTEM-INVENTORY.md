# Pokeapp — design-system inventory (as-is)

Snapshot of every design-related element in the codebase on **2026-09-27**, taken from branch
`feature/adjustments` including its uncommitted working-tree changes. It is an inventory only:
it records what exists and where uses agree or disagree. It makes no recommendation to keep, merge
or remove anything.

**Scanned:** `src/**/*.tsx` (UI components only), all CSS (`src/index.css`, `src/App.css`,
`src/design-tokens.css`, `src/components/ds/ds.css`, the five module stylesheets), `src/theme.ts`,
`src/components/typeColors.ts`, and `design-system/` (docs, token JSON/CSS, HTML mockups).
**Not scanned:** `src/data/**`, module logic files (`*Math.ts`, `store.ts`, `model.ts`, `damage/**`,
query engines and similar), `scripts/`.

**How "Uses" is counted:** for a component, the number of JSX call sites (`<Name`) in `src/`,
excluding the component's own file. For a CSS class, the number of `className` references in
`.tsx` files. For a token, the number of `var(--token)` references in CSS and TSX. **"Ref page
only"** means the element appears only on the design-system reference page (`?ds=1`,
`src/modules/design-system/DesignSystemPage.tsx`) and on no production screen.

## 4. Conflicts — inconsistencies and duplicates

Recorded as found. No resolution implied.

### Same name, different implementation
- **C-1** `FormSectionLabel` is defined twice, in `ds/Navigation.tsx` (`<p>`, string child) and in `ds/FormParts.tsx` (`<h3>` + aside). `FilterPanel` imports the first; the calculators import the second. (A-14)
- **C-2** `MoveSlotTile` and `MoveSlotGrid` are each defined twice, in `ds/DataRows.tsx` (`.ds-move-tile`, read-only) and in `ds/MoveSlotTile.tsx` (`.ds-move-slot`, selectable), with different APIs, classes, padding and label size. (M-10)
- **C-3** `--accent` is declared in `index.css` (purple `#aa3bff` / `#c084fc`) and in `design-tokens.css` (red). Which one applies depends on import order in `main.tsx`. (T-2)
- **C-4** `.num` is declared twice as a global rule, in `App.css` and `typecoverage.css` (identical). (A-10)

### Near-duplicate families (same role, separate code)
- **C-5** Ghost/text buttons: 8 variants (`.ghost-button`, `.nav-trigger`, `.pokedex-back`, `.app-bar-back`, `.species-page-back`, `.tb-ghost`, `.dcalc-link`, `.retry-btn`). They differ in colour at rest, padding, hover treatment (text colour vs fill), focus ring (accent outline at 3px, field-focus outline at 2px, or none) and radius. (A-2)
- **C-6** Switches: 3 (`.ds-toggle`, `ToggleSwitch` `.toggle`, `.tb-switch`) with different sizes (36×20, 2.1×1.05rem, 38×20), off-state colours (`--hairline`, `--code-bg`, `--surface-hover`) and thumb colours (white, `--bg`, grey that turns white). (A-7)
- **C-7** Segmented controls: `.ds-theme-switcher` and `.tc-segmented` are visually identical but separately authored; `.species-scope-segments` differs in track colour, radius, active fill and padding. (M-2)
- **C-8** Range sliders: `.ds-range` and `.tb-range` are rule-for-rule copies, each reading its own identical set of variables (`--ds-slider-*` / `--ds-on-accent` vs `--slider-*` / `--tb-on-accent`). (A-8, T-16)
- **C-9** Text inputs: 5 treatments (`.ds-field-control`, `.tb-input` / `.tb-number`, `.app-controls-field` search, `.global-search-input`, `.ds-search`). Underline colour differs (`--hairline` vs legacy `--border`), and focus is either a 2px accent underline or a 1px colour change. (A-4, T-12)
- **C-10** Selects: 4 treatments (`SelectField`, `.tb-select`, `.tc-select`, `.vg-selector`). One is boxed and filled, the other three are underlined; chevrons differ (unicode ▾ in `SelectField` and `.tc-select`, the native arrow in `.tb-select` and `.vg-selector`). (A-5)
- **C-11** Labels and section headings: letter-spacing takes five values for the same visual role (0.05 / 0.06 / 0.07 / 0.08 / 0.1em); weight is regular in some and bold in others; `.tb-field-label` and `.tb-stat-head` are not uppercase; the species page uses `capitalize`. (A-6, A-14, O-11)
- **C-12** Ghost watermarks: 5 production variants plus the ds component. They differ in position (top-right bleed vs centred at the top), colour source (`--ghost-watermark`, `--text-primary`, `--hero-quiet #999`), opacity multiplier (×1, ×2, ×0.8) and tracking (0.18–0.24em). (A-11)
- **C-13** Floating panels: 8 styles. Border is `--hairline`, legacy `--border` or `--accent`; radius is 4, 8, 10 or 14px or 0.35rem. (M-15)
- **C-14** EV entry: 3 implementations (`EvRow`, `EvStatTable`, Team Builder `SpreadControls`). (M-8)
- **C-15** Base-stat bars: 2 implementations (`.species-stat-bars`, Team Builder `StatTable`). (M-7)
- **C-16** Type-effectiveness charts: 3 implementations; only one colours the multipliers. (O-15)
- **C-17** Species grid card: ds `SpeciesGridCard` (ref page only), production `SpeciesCard`, and an inline copy of the `.species-card*` markup in `Berrydex`. (M-12)
- **C-18** List rows: ds `LedgerRow` (ref page only) vs production `.ledger-list .species-row` vs `DataTable` rows. (M-11)
- **C-19** Detail layouts: `EntityDetailPage` (3 dexes) vs hand-built detail views in 4 dexes vs the species detail page vs ds `SpeciesDetailPanel` / `HeroDetailCard` (ref page only). (O-10, O-11)
- **C-20** Local spacing scales: `--calc-*`, `--tb-*` and `--tc-*` sit alongside the global `--space-*` tokens, with overlapping values (2/4/6/8/12…). (T-11)

### Token drift and bypasses
- **C-21** Three copies of the tokens disagree. The app CSS adds `--font-size-page-title` (in neither the JSON nor the handoff CSS). The handoff CSS lacks `--radius-badge-square` and keeps `--field-*` and `--ledger-*` under dark mode only. The JSON still carries the retired muted type palette. (0, T-8)
- **C-22** Legacy starter variables (`--text`, `--text-h`, `--bg`, `--border`, `--code-bg`, `--accent-bg`) are still referenced about 80 times, mostly in `pokedex.css` and `teamBuilder.css`, beside design-system variables with close but different values. (T-17)
- **C-23** Type colour comes from three sources: `--type-*` via `TypeLabel`; `--type-*` inlined without a fallback in typecoverage; raw `TYPE_COLORS` hexes in `TypeBadge` (as fill) and `TypeFilter` (as text). Type-label weight is regular in `.ds-type` and bold in `.tc-ty`. (T-6, A-9)
- **C-24** Hard-coded values sit beside tokens: about 60 raw font sizes, about 40 raw radii, `.stat-up` / `.stat-down` hexes that duplicate `--stat-*`, `--hero-quiet #999`, `--tb-done #16c247`, and the `.ds-toggle-thumb #fff`. (T-8, T-10, T-3, T-16)
- **C-25** Global type and spacing tokens are overridden locally in `.dcalc` and `.species-page-inner`, so the same token name resolves to different sizes on different screens. (T-8, T-11)
- **C-26** Icon tokens (`--icon-grid`, `--icon-stroke-width`) have no references; icon size and stroke are set per call site (11 sizes, 5 stroke values). Back navigation uses `IconArrowLeft` in most places and `IconChevronLeft` in Team Builder. Sort direction is a unicode ▲/▼ in `DataTable` and a Tabler arrow elsewhere. (T-14, A-16, A-17)
- **C-27** Gender display differs across screens: `·` vs `/` separator, and `--text-primary` vs `--type-water` for male. (M-27)
- **C-28** Accent use outside the four uses in the spec: danger buttons, the female gender sign, slider fills, the egg-marker popover border and `.retry-btn` hover. (T-2)

### Documentation vs code
- **C-29** `DESIGN-SYSTEM.md` §12.1 and §12.6 describe `ToggleSwitch.tsx` as unimported dead code still carrying a `box-shadow`. In code it is imported and rendered in 3 places, and its shadow has been removed. (A-7)
- **C-30** `DESIGN-SYSTEM.md` §5 ("Buttons") says a ghost button is written down as `.ghost-button`; `Button.tsx` says no ghost variant is specified; Team Builder has its own `GhostButton` component. (A-1, A-2)
- **C-31** `GhostWatermark.tsx` describes a constant 5% opacity with the number placed top-right; the token is 0.09 in light mode, and §5 (as corrected against Figma) places the grid watermark centred at the top. (A-11)
- **C-32** `DataRows.tsx` calls the EV row a placeholder until sliders are designed; a slider exists in `EvStatTable` and in Team Builder. (M-8)

### Defined but unreferenced
- **C-33** Tokens with no references: `--radius-badge-square`, `--icon-grid`, `--icon-stroke-width`. Rendered only on the reference page: `--button-primary-*`, `--mini-badge-*`, `--ledger-num-opacity-*`.
- **C-34** ds components rendered only on the reference page: `Button`, `LedgerRow`, `SpeciesGridCard`, `HeroDetailCard`, `SpeciesDetailPanel`, `GhostWatermark`, `SearchFilterRow`, `EvRow`, `EvTotal`, and the `DataRows` version of `MoveSlotGrid`.
- **C-35** CSS with no TSX reference: `.stats`, `.chips`, `.chip`, `.chip-active`, `.rows` (`App.css`); `.stat-up`, `.stat-down` (`pokedex.css`); `#social` rules and `--social-bg` (`index.css`); `--shadow` (`index.css`); the social symbols in `public/icons.svg`.
