# Form field
**Anatomy:** label, control slot, help text, error text. **Props:** required, invalid, hint.
**A11y:** label `for`/id; help+error linked via `aria-describedby`; error text prefixed with icon, color `color.feedback.error.fg`.
**Tokens:** label `font.style.label`/`color.text.default`; help `font.style.caption`/`color.text.muted`; gap `space.2`.
