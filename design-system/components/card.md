# Card
Use sparingly: the reference pages use **no cards** (hairlines + whitespace). Only for overlays/popovers or grouped media. Flat by default; `elevation.1` only for floating layers.
**Tokens:** bg `color.bg.surface`; border `color.border.hairline`; radius `radius.lg`; padding `--d-pad`. Clickable = one link/button with single focus ring.
