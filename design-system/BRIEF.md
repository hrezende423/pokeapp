# pokeapp Design System — Brief (v2)
- **Audience:** solo dev/designer (owner)
- **Platforms/stack:** web, React + plain CSS custom properties (inferred from as-built `ds-*` classes). Output: `dist/tokens.css` only (no Tailwind).
- **Direction:** see PRINCIPLES.md — quiet monochrome canvas, color = meaning, one accent for wayfinding, 3 density tiers.
- **Theming:** light + dark (same semantic names). Figma Starter = 1 mode/collection → separate Light and Dark collections (as in the As-Built file).
- **Brand inputs:** accent red (hue 360, sat 75), Manrope + mono, pure-grey neutrals, 18 Pokémon type colors (+ derived accessible `type-text` inks).
- **v1 scope:** tokens, density, nav, button, input, select, tabs, switch, type-label, stat-bar, key-value-list, section, form-field. **Later:** combobox, segmented control, field-strip, navbar variants.
- **Open:** exact hex from repo CSS (as-built inventory marks some APPROXIMATE); light/dark toggle behavior; owner name.
