Component library — full 95-item pass (v1 draft, revised)

Every remaining component from the original 95-item scope, built consistently from the locked tokens. Light mode only — dark mode is a mechanical token-swap using the rules already documented, not a new design decision.

Fixes applied this round: Stepper arrows now stacked vertically, not side by side · Rating input uses smooth path-based SVG stars · Modal and drawer scrims lightened to a genuinely translucent ~22% overlay, not a near-opaque wash · All placeholder icons throughout (checkmarks, chevrons, search, play, close, arrows, plus, edit, image-fallback) now use a small consistent set of smooth stroke-based SVG icons instead of text/unicode glyphs.
Status: draft, not battle-tested. The 14 components in ds-component-library.html went through multiple real rounds each. These ~81 did not — this is a fast, systematic first pass so nothing in scope is completely undesigned, not a claim every choice here is final. Two principle questions are flagged inline rather than decided silently: whether accent-red extends to error/alert states, and whether a separate status-green is warranted.
